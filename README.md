# Presentación CAETI 2026

Presentación web interactiva para una exposición de 15 minutos sobre el proyecto **TI/26/140 — Arquitectura de Software para la Transformación hacia Sistemas Adaptativos Inteligentes** y su articulación con los proyectos de investigación del CAETI.

## Funciones

- Recorrido de 10 escenas con navegación por botones o teclado.
- Cronómetro de exposición y tiempo sugerido por escena.
- Modo de pantalla completa.
- Mapa interactivo de nueve proyectos, filtrable por línea de investigación.
- Fichas con título, dirección, equipo y relación con la plataforma experimental.
- Galería de capturas de Odoo.
- Espacio preparado para las futuras capturas del entorno colaborativo.

## Desarrollo

```bash
npm install
npm run dev
```

## Validación

```bash
npm run lint
npm run build
```

## Reemplazo de capturas

Las imágenes de gestión se encuentran en `public/assets/screenshots/`. La escena del entorno colaborativo conserva un marcador visual hasta recibir las capturas definitivas.
